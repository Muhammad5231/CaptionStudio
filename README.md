# ✨ Overview

CaptionStudio Pro V3 is a professional desktop application built with Python for generating animated subtitle videos directly from SRT subtitle files.

The software is designed for YouTube Shorts, Instagram Reels, TikTok, Podcasts, Educational Videos, Marketing Content, and Green Screen Caption Videos.

Unlike basic subtitle generators, CaptionStudio includes a complete rendering engine capable of generating premium subtitle videos with customizable typography, animation, shadows, glow effects, gradients, layouts, and live preview.

The project is completely desktop based and does not require cloud rendering.

# ⚙ Installation

## Clone Repository

```bash
git clone https://github.com/yourusername/CaptionStudio-Pro.git
```

---

## Open Folder

```bash
cd CaptionStudio-Pro
```

---

## Install Dependencies

```bash
pip install -r requirements.txt
```

---

## Install FFmpeg

Download FFmpeg and add it to your system PATH.

Windows

```
https://ffmpeg.org/download.html
```

Verify installation

```bash
ffmpeg -version
```
